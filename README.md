# Bí Mặc

Nền tảng kiến thức thời trang và gợi ý phối đồ cho phụ nữ Việt.

Live: https://bi-mac.vercel.app

## Chạy ở máy

```bash
pnpm install
pnpm dev
```

Không cần credential nào. Không cần Supabase, không cần API key.

## Kiểm tra

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```
